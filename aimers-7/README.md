# LG Aimers 7기

식음업장 판매 데이터를 바탕으로 메뉴별 향후 판매량을 예측한 프로젝트입니다.

## 본인 역할

팀장으로 실험 분담과 결과 공유를 이끌었습니다. 팀원이 데이터 그래프를 함께 읽고 변수 설계에 의견을 낼 수 있도록 협업 방식을 조정했습니다.

## 가설 검증

판매량이 높은 요일에 가중치를 부여하면 성능이 좋아질 것으로 예상했지만, 검증에서 Weighted SMAPE가 악화됐습니다. 가중치를 제거하고 시간의 순환성과 시계열 특징을 다시 구성하며 비교했습니다.

가설보다 검증 결과를 기준으로 다음 실험을 정했습니다. 최종 성능과 순위는 평가 기록을 연결한 뒤 기재할 예정입니다.

## 공개 범위

현재는 프로젝트 설명 문서입니다. 분석 코드와 실행 가능한 모델은 포함하지 않았습니다. 재현 자료에는 데이터 분할 방식, 실험별 점수와 최종 제출 결과를 함께 정리할 예정입니다.
